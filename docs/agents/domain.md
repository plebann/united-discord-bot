# Domain docs

This is a single-context repository.

## Before exploring a domain change

- Read `CONTEXT.md` for the canonical vocabulary.
- Read `docs/discord-bot-domain-rules-v1.md` for domain rules.
- Read `docs/discord-bot-architecture-python-sqlite-v2.md` when the change
  affects architecture or layer boundaries.
- Read relevant files in `docs/adr/` if that directory exists.

Use canonical terms from `CONTEXT.md` in issues, specifications, test names,
and implementation. If a needed term is missing, record it through
`/domain-modeling`; do not silently introduce a synonym.
